Workflows

三种模式，各有推荐工具路径

用 Shift+Tab 在 chat → analysis → academic 间切换。自然语言会 soft-route 到对应技能；高风险步骤仍需人确认。

chat

澄清与摸底

普通研究对话，不强制流水线。需要抉择时用唤醒选项；一旦像数据分析或写稿，提醒切到正确模式。

推荐：psyclaw_wake_options · /grill · /brainstorm

analysis

方案、脚本与交接

soft-route 进入 analysis-plan：逐项确认 → 仪式批准 → 本地可复现脚本 → 同意后再核查 → 人审 → /handoff。

推荐：analysis-plan · /plan · /crosscheck · /verify · /handoff

academic

文献、成稿与审稿

仅 soft-route 捆绑学术技能；定稿前两道 AI 核查加人审。Stage 3 五席走 psyclaw_ars_multi_agent，不在主会话假装分席。

推荐：deep-research / academic-paper* / nature-* · psyclaw_cite · psyclaw_ars_multi_agent

Evidence

把声称钉在账本上

没有可定位证据的事实性 Claim 必须标为 uncertain 或被阻断。副作用要有结构化 receipt。

  • 引用可核验 经 Crossref / OpenAlex 等适配器核对后再入账，而不是模型口头引用。
  • 统计外置 计算委托 Python / R / SPSS / Stata / Mplus 或受信任 MCP，并保留脚本与环境信息。
  • 完成本地可审计 Panel 展示门禁、产物与待人确认项；研究正文默认不进遥测。

Install

一分钟装上本地工作台

需要 Node.js ≥ 22.19。装完直接运行 psyclaw。

$ npm install -g psyclaw@0.30.7 && psyclaw

也可用安装脚本： install.sh · README · 当前版本 0.30.7

Difference

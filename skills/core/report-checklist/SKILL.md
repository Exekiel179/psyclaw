# Reporting checklist

Use this before writing `results/report.md`, anything under `paper/`, or `analysis/HANDOFF.md`.

This is a paraphrase of the quantitative journal article reporting standards (JARS-Quant; Appelbaum et al., 2018, American Psychologist). It is not a copy of the APA tables. The source is https://apastyle.apa.org/jars.

- Design, the sample size in each group, exclusions, and missing data.
- Every model term that was estimated: the estimate, its direction, and its uncertainty or p value. Covariates included. Not only the focal term.
- An effect size with the estimate, and the interval when the software returns one.
- Which results were confirmatory and which were exploratory.
- The software and the script path that produced the numbers. No number without that script.
- If cross-check or verify did not run, say the results were not cross-checked (未经核对).

# Structural equation models

Use this for a path model, a latent factor, or SEM. A significant regression is not a structural model.

- State the specification and why it is identified (what is fixed, what is free) before quoting a coefficient.
- Report at least one global fit index and say what was left unfit. Do not add paths after inspecting residuals and then present the revised model as the confirmatory model. A revision is exploratory.
- A summed score is not a latent factor. If the model uses a composite, call it a composite.
- An indirect path inside an SEM still needs the indirect effect and an interval, not only the two component coefficients.

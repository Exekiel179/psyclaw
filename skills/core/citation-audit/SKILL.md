# Citation Audit

Split factual statements into Claims. Require a qualifying source and locator for every supported Claim, preserve contradictory evidence, and downgrade uncertainty instead of filling gaps. A title match, abstract-only record, or model memory is not proof of a result or causal statement.

These are internal checks. In the manuscript and normal conversation, use natural disciplinary prose rather than exposing Claim/Evidence IDs, ledgers, gates, audit labels, or blocked states. For the final reference check, enforce bidirectional matching between in-text citations and the reference list, consistent target style, correct work type, complete verified metadata, stable DOI, alphabetical or numbered ordering as required, and hanging indentation where the style requires it.

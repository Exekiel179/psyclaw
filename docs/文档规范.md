# 文档规范（Document Convention）

> 本文件是 psyclaw 项目内**文档生成与存放位置**的约定真源。panel 的文档识别
> （`/api/documents`）与手稿发现（`/api/manuscript`）按此约定工作；工作流、
> 技能与研究者手工产出也应遵循，这样 panel 才能「导入文档 → 编辑 → 落盘」。

## 1. 目录约定

```
项目根/
├─ paper/                手稿区（论文/报告正文）
│  ├─ 论文初稿.md       可编辑 Markdown 源（panel 手稿编辑器主来源）
│  ├─ 论文初稿_APA7.docx 排版导出（只读产物，勿手改；改 .md 再导出）
│  └─ archive/           历史版本快照（_v{n}.md / _v{n}_APA7.docx）
├─ docs/                 补充文档/参考资料（.md 会被当作手稿候选）
├─ literature/           下载的参考文献全文（<doi-slug>.pdf，只读来源）
├─ notes/
│  └─ manuscript.md      panel「保存手稿」的默认落点（与 paper/*.md 等价）
├─ data/
│  ├─ raw/               原始数据（只读，不写、不改）
│  └─ clean/             清洗后数据集（效应量、中间表等契约数据）
├─ analysis/
│  ├─ scripts/           可复现脚本（薄入口 + 模块）
│  ├─ outputs/           结果/图表/表格（figures/、tables/）
│  └─ report.md          分析报告
├─ outputs/              工作流产物（index.json 登记）
└─ .psyclaw/               账本（只追加，不手改）
   ├─ project.json
   ├─ evidence.jsonl     证据账本（JSONL，逐行一条）
   ├─ claims.jsonl       论断账本（JSONL，含 claim 与 claim-evidence-link）
   ├─ imports.jsonl      文档导入记录（按 sha256 幂等）
   ├─ versions.jsonl     手稿版本账本（按 markdownSha256 幂等）
   ├─ references.jsonl   参考文献存档（按 DOI 幂等）
   ├─ citations.jsonl    引用用途账本（证据 + 引用原因，按 citationId 幂等）
   └─ manifests/         运行清单与 receipt
```

## 2. 文档类型与位置

| 类型 | 位置 | 命名 | 可编辑 | 面板角色 |
|---|---|---|---|---|
| 手稿源 | `paper/` | `*手稿*.md` / `*论文*.md` / `*初稿*.md` | ✅ .md | 手稿编辑器加载（`/api/manuscript` 自动发现） |
| 手稿导出 | `paper/` | `*_APA7.docx` / `*.docx` | 只读 | 可导入（pandoc → md）进编辑器修改 |
| 参考文献/资料 | `docs/` | 任意 `.md/.pdf` | 视情况 | 清单展示；.md 可导入 |
| 原始数据 | `data/raw/` | 问卷导出等 | 只读 | 导入登记为证据（不转换文本） |
| 清洗数据 | `data/clean/` | `effects.csv` 等契约数据 | 工作流写 | 元分析等工作流读取 |
| 报告 | `analysis/report.md`、`outputs/*.md` | — | 工作流写 | 无手稿时的回退来源 |

## 3. 面板手稿发现顺序（/api/manuscript）

1. `notes/manuscript.md`（面板托管）
2. `paper/` 与 `docs/` 下的 `.md`（优先名称含 手稿/论文/初稿/draft/manuscript，否则最新）
3. 回退：`analysis/outputs/meta-analysis.md` → `outputs/literature-review.md` → `notes/HANDOFF.md`

## 4. 文档导入（/api/documents/import）

- 幂等键：源文件 **sha256**（`.psyclaw/imports.jsonl` 记录，重复导入直接返回既有记录）
- `.docx` → pandoc 转 Markdown，载入手稿编辑器；`.md` → 直接读取
- `.xlsx/.csv/.pdf` → 只登记证据（`level: user/metadata`），不转换文本
- 每次导入：
  1. 在 `.psyclaw/evidence.jsonl` 追加证据（`accessStatus: partial`，仅登记来源，
     不冒充已核验；sha256 指纹入库）
  2. 在 `.psyclaw/imports.jsonl` 追加导入记录
  3. 在 `.psyclaw/manifests/` 写 tool receipt

## 5. 生成端要求（给工作流 / 技能）

- 手稿正文一律先产出 `paper/*.md`（可编辑源），`.docx` 仅作为导出交付物。
- 统计结果与图表写入 `analysis/outputs/`，报告正文引用相对路径。
- 任何会进账本的数据都要有 sha256 指纹与来源 locator。
- 旧版项目迁移：把 `paper/*.md` 放入约定位置即被 panel 识别；旧 `.psyclaw/evidence-ledger.json`
  如需迁移，逐条写入 `.psyclaw/evidence.jsonl`（JSONL 格式）。

## 6. 生成时自动落位（publish）

规范不依赖人工放文件——发布动作本身就是系统能力，生成时就完成：

| 入口 | 触发 | 效果 |
|---|---|---|
| `publishManuscript`（src/workflows/publish.ts） | 任何生成端调用 | 写 `paper/<名>.md` + `paper/<名>_APA7.docx`（pandoc，自动探测 `paper/*reference*.docx` 作黑白模板），两个文件都登记证据（sha256, accessStatus=partial），写 receipt + `.psyclaw/publish.jsonl` |
| `psyclaw_workbench` 工具 | 用户说「发布/导出/定稿/投稿论文」「export docx/APA7」 | 把当前手稿发布到 `paper/论文初稿.md` + `paper/论文初稿_APA7.docx` |
| `/api/publish`（panel） | 「发布 Word (APA7)」「发布 Markdown」按钮 | 同上，服务端 pandoc 执行 |
| 身份提示词 | 智能体生成论文时 | 强制：正文先写 `paper/<名>.md`，APA7 导出到 `paper/<名>_APA7.docx`，不许只留在 outputs/ 或根目录 |

发布后 panel 立即识别：`/api/manuscript` 发现 `paper/<名>.md`，`/api/documents` 列出两个产物
（`isManuscript=true`），导入 docx 可反向得到可编辑 md。

## 7. 版本修订（versions）

- 每次发布若内容（sha256）变化 → 版本 +1；旧版归档到 `paper/archive/<名>_v{n}.md` 与
  `paper/archive/<名>_v{n}_APA7.docx`，最新版始终在 `paper/<名>.md`。
- 版本账本：`.psyclaw/versions.jsonl`（逐行一条，按 markdownSha256 幂等；内容未变不产生新版本）。
- panel 手稿编辑器顶部显示当前版本徽标 + 版本下拉，可随时切回历史版本查看/继续编辑。

## 8. 参考文献存档与核验（references）

- 存档：`.psyclaw/references.jsonl`（按 DOI 幂等，逐条含 title/authors/year/venue、
  verified 状态、Crossref+OpenAlex 核验快照、OA 链接、下载路径）。
- 正文引用核验：`/api/references/check` 从正文提取 `(作者 et al., 年份)` / `（张三，2020）`
  类引文，对照存档返回匹配/缺口；缺口的 DOI 通过「核验并存档」补齐。
- 全文下载：`/api/references/download` 用 OpenAlex 的 OA 链接下载 PDF 到 `literature/<slug>.pdf`
  （仅 https/http、≤40MB），登记证据（sha256, partial）；非开放获取时诚实返回，转机构
  全文流程（psyclaw_workbench 浏览器人工登录）。

### 8.1 引用用途账本（citations）

生成论文时每加一条正文引用，都要同时登记**证据**与**引用原因**：

- 账本：`.psyclaw/citations.jsonl`（逐行一条，按 citationId 幂等）——每条含 DOI、首作者姓氏、
  年份、**引用原因（一句）**、被引句上下文、章节、关联论断（可选）、核验状态、登记时间。
- 登记入口：
  - `psyclaw_cite` 工具（智能体写作时每次引用都调用；自动核验 DOI → 存档参考文献 →
    追加引用用途）
  - `/api/citations`（panel「登记引用用途」表单）
- 语义：引用即使未能双源核验也**如实登记**（`verified=false`），引用原因永不丢失；
  核验通过时参考文献同步进入存档（`.psyclaw/references.jsonl`），正文核验（§8）即可命中。

## 9. 产出质量清单（交付硬检查）

- **成本预告知**：文献检索与核验、全稿写作、DOCX 导出等重阶段开始前，告知预估 token/费用/时间并等待确认。
- **图表**：森林图（95%CI）/热力图/小提琴+蜂群/哑铃/雷达/瀑布/残差诊断优先，禁止默认样式裸条形图；统一 300DPI PNG + 可编辑 SVG、≥9pt 标签、数值标注。
- **图表文字**：图内**一律英文**（标题/坐标/图例/注释），禁止中文（字体跨系统不一致）；图标题与中文说明用 caption 文本放在图上/图下（`**图N …**` 行），不嵌入图像；中文变量名→英文缩写放 caption 中。
- **配色**：分类色用 Okabe-Ito 等高区分度调色板，连续色用 RdBu_r/viridis/coolwarm 加 colorbar；禁止 matplotlib 默认色与灰调单色；加显著性星标、CI 误差条、透明层次。
- **参考文献**：`references.md` 与论文参考文献区必须是 **APA 7 悬挂缩进条目列表（非表格）**：`Author, A. A., & B. B. (Year). Title. Journal, Vol(Issue), Pages. https://doi.org/...`；1–20 位作者全列、≥21 用省略号；禁空作者/空卷期/页码重复/作者列表混入 et al.；RIS 仅作导入用。
- **表格**：三线表=顶框/底框 1.5 磅（OOXML sz=12）+ 表头下框 0.5 磅（sz=4），其余无边框无底纹；md 源即三线；DOCX 导出后运行 `postprocess_docx.py` 并核验边框；宽表（>6 列或 >20 行）用 9pt + 横向页面；**NaN/Inf 一律替换为 — 并加注**。
- **摘要**：目的/方法/结果/结论四段式；结果含均值±SD、率、检验统计量与 95%CI/效应量；结论衔接政策并写明局限；关键词 3-6 个含研究方法。
- **效率**：命令输出重定向文件后选择性读取；长文档分节写作；大 JSON 用 grep；长会话主动压缩或分段。
- **工具调用纪律**：单会话工具调用控制在 ~40–60 次内；数据探查用一次性剖析脚本写 JSON、之后读 JSON（禁止 50+ 次内联 `python -c`）；管线用 `run_all.py` 收口、失败只重跑失败步骤；同类检查合并单条命令；用退出码验证写入（不 ls/cat 确认）；每文件至多读一次；整写优先于多次小 edit。

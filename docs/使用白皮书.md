## 1. 产品概述

psyclaw 是面向社会科学研究的**证据驱动科研智能体**：它在本地沙盒内驱动 LLM（默认 DeepSeek，可切换 OpenAI / Anthropic / Google），以**可验证的证据账本（Claim-Evidence Ledger）**为唯一事实来源，完成从课题立项、文献综述、统计委托、论文写作、引用核验到版本化发布的完整研究闭环。

它不是"会聊天的论文生成器"，而是一套**把研究过程结构化为可审计状态**的系统：每一条论断、每一份证据、每一次引用、每一个产物都有真实文件、SHA-256 指纹与结构化 receipt 背书。

### 1.1 设计原则

1. **证据先行，杜绝编造**：引用必须双源核验（Crossref + OpenAlex），无法核验的一律如实标为 `uncertain` 或阻断，绝不虚构。
2. **统计委托，核心不造数**：psyclaw 核心不实现统计算法；I²、Egger、中介检验等一律委托成熟工具（R metafor、Python statsmodels 等），生成可复现脚本，不伪造任何统计数值。
3. **范式感知**：社会科学证据标准按研究范式配置——元分析/实验按 RCT 级标准，质性/历史/政策研究不套用同一金标准。
4. **一切副作用有 receipt**：任何写入都有幂等键、审批记录与结构化 receipt，Verifier 不认"模型口头声称"。
5. **生成即落位**：文档按统一规范（`docs/文档规范.md`）在生成时自动放到约定位置，panel 即刻识别。
6. **诚实失败**：缺数据就阻断（`meta:effect-data-missing`），下载不了就如实返回"非开放获取"，绝不假装成功。

## 2. 系统架构

```
┌─────────────────────────────────────────────────────────┐
│  用户入口                                                  │
│  ├─ 终端：psyclaw 对话 / psyclaw shell / 对话内 /panel       │
│  └─ 面板：手稿编辑 / 产物 / 引用 / 看板（浏览器）            │
├─────────────────────────────────────────────────────────┤
│  psyclaw 核心                                               │
│  ├─ Pi 运行时适配（@earendil-works/pi-coding-agent 0.84.1）│
│  ├─ 工具：psyclaw_workbench（路由）、psyclaw_skill、psyclaw_cite│
│  ├─ 工作流：literature-review / analysis-delegation /     │
│  │          writing-review / expert-review / meta-analysis│
│  │          / publish                                     │
│  └─ 门禁：证据门禁 / 预注册门禁 / 引用核验门禁              │
├─────────────────────────────────────────────────────────┤
│  项目账本（真实文件，追加式 JSONL）                         │
│  .psyclaw/evidence.jsonl  证据（含 sha256、accessStatus）    │
│  .psyclaw/claims.jsonl    论断 + Claim-Evidence 链接         │
│  .psyclaw/references.jsonl 参考文献存档（DOI 幂等）          │
│  .psyclaw/citations.jsonl 引用用途（证据+引用原因）          │
│  .psyclaw/versions.jsonl / publish.jsonl  版本账本           │
│  .psyclaw/imports.jsonl   文档导入记录（sha256 幂等）         │
│  .psyclaw/manifests/      receipt / manifest / verdict       │
└─────────────────────────────────────────────────────────┘
```

关键点：**账本是追加式（append-only）JSONL**，只增不改；任何模型都无法事后改写历史。证据的 `accessStatus` 从 `partial`（仅登记来源）到 `verified`（通过独立核验）由审计流程提升，panel 不冒充已核验。

## 3. 快速上手

```bash
# 1) 安装（任意平台）
npm install -g psyclaw@0.24.0

# 2) 配置模型提供商（首次）
psyclaw wizard          # 或 psyclaw setup --provider deepseek

# 3) 创建研究项目
psyclaw init "大学生社会支持对就业焦虑的影响" --paradigm survey-observational

# 4) 进入智能体对话（默认入口）
psyclaw
```

启动后在对话中可以直接：
- 委托任务（"做文献综述""审查统计方案"）——psyclaw_workbench 自动路由
- 打开可视化面板：输入 `/panel`（浏览器工作台）
- 引用文献时系统自动核验并登记用途

### 3.1 面板（对话内 /panel）

| 视图 | 能力 |
|---|---|
| 手稿编辑与核验 | 富文本/Markdown 编辑、选词关联论断、证据审查、**真实 DOI 核验**、版本切换、发布 Word(APA7)/Markdown |
| 运行看板 | 任务进度、门禁状态、证据覆盖率、Token 用量与**预估费用** |
| 产物证据 | 手稿预览与论断探针、**文档清单与导入**（docx→md）、产物指纹表、SVG 拖拽编辑 |
| 参考文献 | 存档列表（核验状态）、**正文引用核验**、OA 全文下载、**引用用途登记** |
| 人工确认 | HITL 检查点与裁决记录 |

## 4. 核心概念

### 4.1 研究范式（10 种）

`survey-observational`、`qualitative-thematic`、`experimental`、`quasi-experimental`、`longitudinal-panel`、`meta-analysis`、`ethnographic`、`historical-documentary`、`policy-legal`、`mixed-methods`

范式决定证据门槛（如元分析要求 fulltext 级证据与效应量数据契约）与报告字段。

### 4.2 Claim-Evidence Ledger

- **Claim（论断）**：正文中可检验的陈述，带类型（existence/definition/method/result/interpretation）与状态（supported/uncertain/unsupported）。
- **Evidence（证据）**：支持论断的来源，含 locator、级别（metadata/abstract/snippet/fulltext/user）、sha256、accessStatus。
- **Link（链接）**：`supports` / `contradicts` / `context` 关系，供文献脉络图与矛盾优先排序。

### 4.3 门禁（Gates）

工作流在关键节点做诚实检查：证据不足 → `review:sources` 阻断；预注册缺失 → `analysis:pre-registration` 阻断（质性/历史/政策范式豁免）；元分析无效应量数据集 → `meta:effect-data-missing` 阻断。阻断即产出 `draft-blocked` 产物并写 verdict，绝不跳过门禁假装完成。

### 4.4 版本

每次发布（内容变化）→ 版本 +1：最新版在 `paper/<名>.md` + `paper/<名>_APA7.docx`，历史版归档到 `paper/archive/<名>_v{n}.md`；版本账本按 sha256 幂等，内容未变不产生新版本。

## 5. 文档规范（生成即落位）

| 位置 | 内容 |
|---|---|
| `paper/` | 手稿区：`<名>.md` 可编辑源 + `<名>_APA7.docx` 导出 + `archive/` 历史版本 |
| `docs/` | 补充文档（.md 也会被手稿发现逻辑识别） |
| `literature/` | 下载的参考文献全文（`<doi-slug>.pdf`） |
| `data/raw/` `data/clean/` | 原始数据（只读）/ 清洗数据集（效应量等契约数据） |
| `analysis/scripts/` `analysis/outputs/` | 可复现脚本 / 结果、图表、表格 |
| `outputs/` | 工作流产物（index.json 登记） |
| `.psyclaw/` | 全部账本与 receipt（只追加） |

发布动作本身就是系统能力：`publishManuscript` 写 `paper/<名>.md` + `paper/<名>_APA7.docx`（pandoc，自动探测黑白 reference-doc）、登记两个文件证据（sha256）、写版本与 receipt。生成端（智能体工具、面板按钮、`/api/publish`）全部走同一路径，**无需人工摆放文件**。

## 6. 研究工作流

```
psyclaw init（立项，记范式/假设/伦理）→ /research 或 /panel
  → evidence add 登记文献/数据（sha256 指纹，只读）
  → 对话中「做文献综述」→ literature-review（证据覆盖率 + 缺口披露）
  → 对话中「审查统计方案」→ analysis-delegation（委托 R/Python，不造数）
  → 写作 → 写作/专家评审（writing-review / expert-review）
  → 引用核验 + 全文下载 → 版本化发布（paper/）
  → 人工裁决（HITL）→ HANDOFF 移交
```

**元分析专项**（对话中说「做元分析」，如 `meta-analysis --target online-learning-engagement`）：
1. `intake`：真实 OpenAlex 检索实证研究
2. `capture`：绑定效应量数据集契约（`data/clean/effects.csv`：study_id, effect_size, standard_error）
3. `audit`：委托 R metafor 生成 REML 随机效应、I²、Egger 漏斗检验与森林图脚本
4. `brief`：研究清单入账本 + 报告落盘

无数据集时如实阻断，**绝不伪造 I²/Egger 数值**。

## 7. 引用与核验体系（核心特色）

### 7.1 双源核验
每条 DOI 走 Crossref + OpenAlex 双重校验（标题/作者/年份一致才 `verified`；不一致报 mismatch；网络失败返回 error，不假通过）。

### 7.2 参考文献存档 `.psyclaw/references.jsonl`
按 DOI 幂等；含核验快照、OA 链接、下载路径。**每次引用都从这里查询，查询即核验**。

### 7.3 引用用途账本 `.psyclaw/citations.jsonl`
生成论文时，智能体通过 `psyclaw_cite` 工具为**每一条正文引用**登记：
- **证据**：DOI、首作者、年份、核验状态
- **引用原因**：一句（如"支持：社会支持缓冲压力假说"）
- 被引句上下文、章节、关联论断（可选）

无法核验的 DOI 也**如实登记**（`verified=false`），引用原因永不丢失。存档能回答"这条引用为什么出现在这里"。

### 7.4 正文引用核验
面板「核验正文引用」从手稿提取 `(Kessler et al., 2005; Wanberg et al., 2010)` 与 `（张三，2020）` 类引文，对照存档返回匹配/缺口清单。

### 7.5 全文下载
`/api/references/download` 经 OpenAlex OA 链接下载 PDF 到 `literature/`（仅 https、≤40MB、登记 sha256 证据）；非开放获取如实返回并转机构全文流程（浏览器人工登录）。

## 8. 安全、隐私与伦理

- **凭据不外泄**：API Key 存于系统认证存储，panel/日志/账本绝不出现密钥内容；模型切换不暴露凭据。
- **原始数据只读**：`data/raw`、凭据、`.git`、符号链接目标不可写。
- **敏感资料不出本地**：原始/敏感资料未经授权不进入外部模型或网络。
- **人工裁决（HITL）**：重要假设、清洗规则、异常结论等由人类确认并记录裁决；生成文档自动打 `needs-human-review` 标记并在交付摘要列出"需人工校准"项。
- **许可边界**：技能/MCP/插件默认"发现但不执行"，启用前需来源、版本、哈希、许可与信任预检；安装需 `--yes` 显式确认并写 dependency receipt。

## 9. 典型使用场景

1. **问卷实证研究**（如就业焦虑中介分析）：init → 数据登记 → 分析委托（Python）→ 论文写作 → 引用核验 → APA7 发布，全程账本可审计。
2. **元分析/系统综述**：OpenAlex 检索 + 效应量契约 + R metafor 委托 + 森林图，阻断诚实。
3. **文献综述**：证据覆盖率、矛盾优先排序、缺口披露。
4. **教学与演示**：证据链可视化、版本追溯、引用用途存档，展示"AI 研究"的严谨性。

## 10. 限制与边界

- **不替代人工判断**：统计结论、伦理决策、投稿判断仍需人类；面板的 HITL 与"需人工校准"标记是强制通道。
- **核心不计算统计**：psyclaw 不实现统计算法，需本地有 R/Python 及相应包才能执行委托脚本。
- **开放获取依赖**：付费文献下载走机构登录流程，系统只保证 OA 途径的自动下载。
- **模型能力边界**：核验与门禁保证过程诚实，但研究质量最终取决于检索到的真实文献与数据质量。

## 11. 常见问题（FAQ）

**Q: 装好后如何配置模型？** `psyclaw wizard` 或 `psyclaw setup --provider deepseek`（默认 DeepSeek，可切换）。

**Q: 引用没反应/没有后续？** 面板只能在 psyclaw 对话中输入 `/panel` 打开（面板聊天由该会话提供智能体通道）；论断"无法核验"通常是未登记证据，先核验 DOI / 登记证据 / 下载全文再追问。

**Q: DOCX 导出需要什么？** Pandoc（`brew install pandoc` / winget / apt），自动探测黑白 reference-doc 保证 APA7 黑白三线表。

**Q: 元分析提示缺数据？** 按契约提供 `data/clean/effects.csv`（study_id, effect_size, standard_error）后重跑。

**Q: 面板里中文文件名打不开？** 已按 RFC 5987 处理，任意平台均可。

**Q: npm 装不到 v0.24？** 预发布阶段使用 `npm install -g psyclaw@0.24.0 --registry https://registry.npmjs.org`；通过剩余发布门槛后再将该版本提升为 `latest`。

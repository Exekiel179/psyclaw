## 三、测评发现并修复的真实问题

1. **receipt 落点不一致（已修复）**：`assertSafeProjectPath(root, "manifests/…")` 把 receipt 写到 `root/manifests/`，而规范/`projectPaths.manifests`/工作流清单在 `.psyclaw/manifests/`。已统一为 `.psyclaw/manifests/`（src/panel/server.ts ×8、src/workflows/publish.ts ×1）。
2. **手稿发现顺序（已修复）**：报告回退（如 HANDOFF.md）先于 `paper/*.md` 命中，导致已有论文初稿时面板却显示 HANDOFF。已调整为先 `notes/manuscript.md` → `paper|docs/*.md` → 报告回退（src/project/manuscript.ts）。

本轮全量测试 **42 个 test files / 254 tests 全绿**，分模块测评 **31/31**。

## 四、测评方法说明

- **离线确定性**：DOI 核验、OpenAlex 检索、OA 下载全部注入 fake fetch（符合评测框架"默认不联网"）；CLI 探测用 `spawnSync` 真实执行 dist 构建产物。
- **真实路径**：每个探测在临时项目上以用户视角操作（写文件、起 panel server、调 CLI）。
- **硬门对齐**：全部 31 项探测未触碰任何"虚构/越权/伪造数值"类 hard fail；阻断行为（缺数据、付费墙、路径逃逸）均按框架要求"诚实失败"。
- 复跑命令：`pnpm build && pnpm eval:modules`；评分卡：`evals/reports/modules-latest.json`。
